# 截图助手

常驻托盘的 Windows 截图工具：全局快捷键框选截图，支持标注、贴图与延时截图。Electron 39，界面为与「时光助手」同源的玻璃拟态设计（浅/深色）。唯一运行时依赖为 [koffi](https://koffi.dev)（预编译 FFI，用于窗口智能识别，无需编译环境）。

## 功能

- **截图**：全局快捷键 `F1`（被占用时自动回退 `Ctrl+Alt+A`），也可通过托盘右键菜单触发；托盘左键单击打开主窗口（设置页）；每屏一个覆盖层显示冻结画面，**窗口智能识别**（鼠标悬停自动高亮所在窗口，单击直接选中；按住拖拽则转手动框选），拖拽框选（可移动/八向手柄重调），带放大镜（像素网格 + HEX 取色）与尺寸标签；`Esc` 取消，`Enter` / 双击复制。
- **标注**：矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克；撤销/重做（`Ctrl+Z` / `Ctrl+Y`）；8 色色板 + 3 档粗细；单键 `R/E/A/P/M/T/B` 切换工具。
- **文字识别（OCR）**：工具条「扫描」按钮或单键 `O`，调用 Windows 自带 WinRT OCR 引擎离线识别（零第三方依赖，需系统已安装 OCR 语言功能，中文系统默认具备）；识别前自动 2 倍 bicubic 放大，小字号 UI 文字识别率大幅提升；结果面板逐行展示，点击复制本行、「复制全部」一键复制；`Esc` 先关面板再退截图。
- **完成动作**：复制到剪贴板、保存（每次询问 / 自动保存到「图片\截图助手」）、贴图、关闭。
- **贴图（图钉）**：截图钉在桌面置顶显示，左键拖动、滚轮以光标为锚缩放、右键菜单（复制 / 另存 / 不透明度 / 关闭）、双击关闭；贴图本身不会进入下一次截图。
- **延时截图**：托盘菜单 3 秒 / 5 秒，屏幕中央倒计时（不抢焦点，点击取消）。
- **历史记录**：每次完成的截图（复制 / 保存 / 贴图）自动存入历史（最近 20 条，超出自动淘汰最旧）；同时自动合并扫描**本地保存目录**中最近的 20 张 PNG（带「本地」标记）；主窗口「历史记录」页签，支持缩略图预览、复制、贴图（居中钉出，超大图缩至 80% 工作区）、另存（本地条目为「打开位置」）、单条删除（本地条目删除真删文件，带确认）与清空（仅清应用内历史，不动本地文件）。
- **主窗口**：左侧导航两个页签——「设置」（快捷键 / 保存 / 贴图 / 外观 / 通用）与「历史记录」；托盘「历史记录」「设置」分别直达对应页签。

## 开发

```bash
npm install
npm start        # 启动（开发模式）
npm run icon     # 重新生成 assets/icon.png、tray.png
npm run dist     # 打包 nsis 安装包 + portable 免安装版到 dist/
```

## 架构

```
src/
├── main.js          主进程：生命周期/托盘/快捷键/倒计时/设置窗口/IPC
├── preload.js       contextBridge 安全桥（事件白名单）
├── lib/
│   ├── store.js     设置 JSON 原子写入
│   ├── capture.js   截图引擎：抓屏/覆盖层窗口池/完成动作/贴图窗口
│   ├── history.js   截图历史存储（PNG + 缩略图索引，上限 20 条）
│   ├── win32.js     窗口智能识别（koffi FFI：Z 序遍历 + DWM 边界）
│   ├── ocr.js       OCR 桥接（临时文件 + PowerShell）
│   └── ocr.ps1      WinRT OCR 调用脚本（Windows 自带引擎）
└── renderer/
    ├── overlay.*    选区 + 标注（核心交互）
    ├── pin.*        贴图窗口
    ├── countdown.*  倒计时窗
    ├── main.*       主窗口（设置 / 历史记录 页签）
    └── tokens.css   设计 token（与时光助手同源）
```

坐标约定：渲染层一律逻辑像素（DIP），导出时按 dpr 裁剪为物理分辨率；覆盖层窗口按显示器建池复用，二次触发秒开。

## 已知边界

- 选区限单屏内，不支持跨屏框选；不支持滚动长截图、录屏（计划迭代）。
- 窗口识别对管理员权限/UWP 挂起窗口自动降级为手动框选；Tab 切换候选窗口暂未实现。
- 快捷键固定 `F1`，暂不可自定义。
